# Furniture models

Drop 3D models here, named after the fixture category, and the 3D view uses
them automatically. Anything missing falls back to the built-in primitive
shapes, so this folder can be filled one piece at a time.

    sofa.usdz   bed.usdz   toilet.usdz   sink.usdz   bathtub.usdz …

Full naming and orientation contract, plus where to get free CC0 models:
`Docs/FURNITURE_MODELS.md`.
